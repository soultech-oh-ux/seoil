# AI와 기독교 윤리 100문 100답 · 성도 교육용 워크북

책 **《AI와 기독교 윤리 100문 100답》**(오경근 목사 지음)의 100개 질문을
일반 교회 성도가 **읽고 · 묻고 · 답하고 · 토론하며** 자연스럽게 이해할 수 있도록
각 질문마다 한 장(**A4 앞뒤 2페이지**)으로 만든 교육용 워크북 모음입니다.

## 📂 폴더 구성

```
ai-ethics-workbook/
├── index.html          ← 전체 100과 목록·바로가기 (여기서 시작)
├── README.md           ← 이 파일
├── workbooks/
│   ├── Q01.html ~ Q100.html    ← 워크북 100개 (HTML · 각 A4 2페이지)
├── workbooks-docx/
│   ├── Q01.docx ~ Q100.docx    ← 워크북 100개 (Word · 각 A4 2페이지, 편집 가능)
└── _source/            ← 원문에서 추출한 질문·답변 데이터(JSON) — 재생성/검증용
```

> **두 가지 형식 제공** — 바로 인쇄·배포는 `workbooks/`(HTML), Word에서 문구를
> 수정·재편집하려면 `workbooks-docx/`(.docx)를 사용하세요. 두 형식의 내용은 동일합니다.

| 면 | 섹션 | 내용 |

| | ✨ 한 줄 정리 | 기억할 핵심 메시지 |

## 🖨️ 사용·인쇄 방법

### HTML 버전 (`workbooks/`)
1. `index.html`을 브라우저(크롬·엣지 등)로 엽니다.
2. 원하는 질문을 클릭하면 해당 워크북이 열립니다.
3. **인쇄(Ctrl/⌘ + P)** → 용지 **A4** → **양면(단면 인쇄 시 2장)** 을 선택하면
   앞뒤 2페이지짜리 유인물이 완성됩니다.
4. 프린터 대신 **'PDF로 저장'** 을 선택하면 PDF 파일로도 보관·배포할 수 있습니다.

### Word 버전 (`workbooks-docx/`)
1. `workbooks-docx/` 폴더에서 원하는 `Q##.docx`를 **한글(HWP)·MS Word**로 엽니다.
2. 문구·성경 구절·토론 질문을 자유롭게 **수정·편집**할 수 있습니다.
3. **인쇄** → 용지 **A4** → **양면** 선택 시 앞뒤 2페이지 유인물이 됩니다.

> 💡 소그룹 모임에서는 앞면(설명·성경)을 함께 읽은 뒤,
> 뒷면(문답·토론)으로 자연스럽게 대화를 이어가도록 설계되었습니다.

## 📖 활용 예시

- **소그룹·구역 모임**: 매주 한 과씩, 앞면을 읽고 뒷면으로 나눔
- **제자훈련·성경공부**: 10개 부(部)를 10주 커리큘럼으로
- **가정예배**: 부모와 자녀가 한 질문씩 함께 대화
- **주보·게시판**: 한 주 한 장씩 배포
