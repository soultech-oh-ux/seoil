천장형 대형 턴테이블 모터 구동부 설계

17분 / 450° 회전 · Arduino · TouchDesigner 연동
설계 개요 문서 · 2026-05-15

1회전 속도 계산 (출력축 기준)

항목값
회전각450° (1.25 바퀴)
시간17 분 (1,020 초)
각속도0.441 °/sec
RPM약 0.0735 RPM (매우 저속)
모터를 직결할 수 없을 만큼 느립니다. 반드시 큰 감속비(1:1,000 이상)가 필요합니다.

2추천 구동 방식 (3가지)

A. 슬루잉 드라이브(Slewing Drive) + 스텝모터가장 추천

  • 천장형 회전 무대·CCTV 폴·태양광 추적기에서 쓰는 웜기어 + 선회베어링 일체형 부품
  • 감속비 1:60~1:120 (내장) + 스텝모터 마이크로스텝(1:16~32) = 사실상 1:2,000~1:4,000
  • 웜기어 셀프락 → 정전 시에도 상판이 떨어지지 않음 (천장형의 핵심 안전)
  • 예: SE3, SE5, SE7 시리즈 (중국산 5~15만 원대, 수 톤 하중 지지)

B. NEMA34 스텝모터 + 유성감속기 + 링기어대안

  • 감속기(1:100) + 외부 링기어/풀리(1:5) = 1:500 → 마이크로스텝까지 합쳐 충분
  • 슬루잉 베어링은 별도 장착 필요 (구조 복잡)

C. AC 기어드모터(웜) + 인코더 + Arduino PID비추천

  • 저렴하지만 정밀 각도 제어가 까다로움 → TouchDesigner 동기화에 불리

6제어 흐름 (TouchDesigner)

  1. TouchDesigner Serial DAT로 Arduino에 "GO 450 1020\n" 같은 명령 전송
  2. Arduino가 AccelStepper 라이브러리로 450°에 해당하는 스텝 수를 17분에 등속 분배
  3. Arduino → TouchDesigner로 1Hz 위치 피드백 수신 → 화면 동기화

7다음 확인 필요 항목

설계 확정을 위해 아래 정보가 필요합니다.

  • 상판의 직경 · 무게 · 재질 — 슬루잉 드라이브 토크 산정
  • 천장 구조 — 콘크리트인지 H빔인지 (앵커 설계)
  • 회전 방향 — 한 방향 회전인지, 왕복인지, 17분 후 복귀 시간은?
  • TouchDesigner 동기 정밀도 — 초 단위 OK / 프레임 단위(33ms)면 인코더 피드백 필수
  • 예산 범위
위 5가지를 알려주시면 슬루잉 드라이브 모델 · 모터 토크 · 전체 BOM을 구체적인 숫자로 확정해 드릴 수 있습니다.
